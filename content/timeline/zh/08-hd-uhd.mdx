一组码要变成光，经过三步。三基色和白点决定 (1, 0, 0) 落在色度图的哪一点。用这套基色和白点解出亮度行，Y 里 R、G、B 各占多少。光电曲线决定光怎么写成码、码怎么还原成光。峰值有多亮在第三步。

每支基色先写成自己的亮度等于 1 的方向 (x/y, 1, (1−x−y)/y)，三列组成矩阵 P。白点也写成 Y=1 的 XYZ。解 P · (kr, kg, kb) = 白点，三个数加起来是 1，这就是 Y = kr R + kg G + kb B。白点或任一基色变了，这一行就得重解。演播里的 Y′CbCr 把同一组系数用在做过光电曲线的 R′G′B′ 上。

1953 年 NTSC 的基色是红 (0.67, 0.33)、绿 (0.21, 0.71)、蓝 (0.14, 0.08)，白点是光源 C，大约 6774 K，坐标 (0.310, 0.316)。按它们解出来就是 0.299 / 0.587 / 0.114。525 是行数，NTSC 是加在这套行数上的副载波。之后显像管换了粉。SMPTE 170M 记下美国 525 行监视器实际使用的 SMPTE-C：红 (0.630, 0.340)、绿 (0.310, 0.595)、蓝 (0.155, 0.070)，白点 D65。按这套粉重解是 0.2124 / 0.7011 / 0.0866。接口没有改用这一行。

625 是行数。PAL 和 SECAM 是两种副载波，都跑在 625 行上。EBU 写的是欧洲演播监视器的粉，BT.470 对这两种制式用同一组：红 (0.640, 0.330)、绿 (0.290, 0.600)、蓝 (0.150, 0.060)，白点 D65。按粉重解是 0.2220 / 0.7067 / 0.0713。和 SMPTE-C 不是同一块色域，kb 差在 0.087 和 0.071。601 的接口两边仍用 1953 年那一行。

D65 是 CIE 的日光白，相关色温 6504 K，坐标 (0.3127, 0.3290)。R、G、B 一起满幅时，光要落在这一点。同一套 1953 基色若改配 D65，亮度行会从 0.299 / 0.587 / 0.114 变成大约 0.290 / 0.606 / 0.105。白点单独就会改系数。

1990 年 BT.709 为高清交换规定一套基色，白点 D65：红 (0.640, 0.330)、绿 (0.300, 0.600)、蓝 (0.150, 0.060)。红和蓝与 EBU 重合，绿的 x 差 0.01。按这套基色和 D65 重解，得到 0.2126 / 0.7152 / 0.0722，接口就用这一行。系数和 601 差一截，是因为整行重解了，而 601 的行还停在 1953 年。sRGB 抄走了这三基色，曲线和满幅范围另算。摄像机曲线是 0.45 次方的分段函数。显示器约 2.4 的伽马是 2011 年的 BT.1886。

2012 年 BT.2020 把顶点放到光谱上，对应红 630 nm、绿 532 nm、蓝 467 nm，坐标红 (0.708, 0.292)、绿 (0.170, 0.797)、蓝 (0.131, 0.046)。再按 D65 重解，得到 0.2627 / 0.6780 / 0.0593。曲线形状仍和 709 的摄像机曲线相同。绿的顶点移动最大。大约覆盖 CIE 1931 的 75.8%，709 大约 35.9%。

BT.709 同时替换各地不兼容的早期高清。SMPTE 240M 是 1125 行里的 1035 有效行，三基色和曲线都不同。709 把有效行定为 1080，总行数仍是 1125 = 3²×5³，所以 1080i 每场还是 562.5 行。1080 = 2³×3³×5，不能被 16 整除，编码高度常补到 1088。幅面是 1920×1080、16:9、方像素。隔行和逐行都在建议书里。帧率包括 24、25、30、50、60 和 1000/1001。1280×720 不在 BT.709 里，它是 BT.1543 / SMPTE 296M，颜色借用 709。720p 的总行数 750 = 2×3×5³。量化仍是 16–235。常见 1080i 4:2:2 的采样钟是 74.25 MHz，分数帧率除以 1.001。

BT.2020 的幅面是 3840×2160 与 7680×4320，方像素，只走逐行，10 或 12 bit，帧率延伸到 120。播出里常见的是非恒定亮度 Y′CbCr。2160p30 一族常见 297 MHz，2160p60 一族常见 594 MHz。

标成 2020 的文件，分级仍可能全部落在 709 三角形里。按满色域去转换会过饱和。见 <PLink id="tag-2020-content-709" />。同一景物在宽列和窄列里差多少，见 <PLink id="primaries" />。编码用一行、解码用另一行，见 <PLink id="matrices" />。

BT.2100 沿用 2020 的三基色，把曲线换成 PQ 或 HLG。同样写着 2020 的文件至少有三种：SDR 曲线、PQ、HLG。本期配方停在 SDR 矩阵。见 <PLink id="bt2100-boundary" />。

高清里隔行仍能当壳：1080p25 可以 PsF 进 1080i50，1080i50 摄像机则是相邻时刻的两场，24p 进 1080i60 多半是 3:2。见 <PLink id="psf-vs-adjacent" />。
